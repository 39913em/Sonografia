Sobre SONOGRAFÍA · ERRORES VISIONOROS
Errores Visionoros — el error como materialidad

SONOGRAFÍA · ERRORES VISIONOROS es un instrumento experimental de databending: toma una fotografía, la convierte en un flujo crudo de bytes, le aplica una textura de corrupción deliberada y reproduce ese resultado como si fuera audio. Lo que se escucha (ruido, glitches, artefactos) se analiza automáticamente y se traduce en una partitura musical real, con notas, compases y clave, lista para exportar.

Es una máquina de traducir errores, el ruido que produce un archivo de imagen, se convierte en material sonoro y luego en notación. El error de lectura se documenta, se afina y se convierte en partitura.

¿Cómo funciona?

Paso 1
Imagen → bytes crudos (BMP)
Paso 2
Textura de corrupción sobre los bytes
Paso 3
Bytes → audio (Web Audio API)
Paso 4
Análisis espectral (FFT) del audio
Paso 5
Eventos detectados → secuencia musical
Paso 6
Secuencia → partitura (VexFlow)

¿Qué puedes exportar?

Cada sesión puede exportarse como PDF, PNG, WAV, MIDI y CSV. Todo se genera y descarga local, nada pasa por un servidor.

¿Por qué existe?

El databending es la práctica de manipular datos de un formato interpretándolos como si fueran de otro, tiene una larga tradición en el arte digital y la música experimental. SONOGRAFÍA · ERRORES VISIONOROS toma esa idea y la vuelve accesible desde el navegador, sin instalar nada, y le agrega una capa de traducción musical formal para que el resultado se pueda leer, tocar o llevar a otro instrumento.

Tecnología

Es una aplicación 100% del lado del cliente: HTML, CSS y JavaScript puro, sin frameworks ni build. Usa la Web Audio API para síntesis y análisis de audio, Canvas 2D para las visualizaciones, VexFlow para el renderizado de la partitura, @tonejs/midi para exportar MIDI y jsPDF para exportar PDF.
